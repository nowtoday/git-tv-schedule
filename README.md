# 이번 주 편성표

공개 Google Sheets의 오늘 방송 편성을 GitHub Actions가 매일 가져와 저장소의 `schedule.json`에 요일별로 누적하고, 사용자가 요청하면 오늘 편성을 브라우저에서 바로 가져오는 개인용 정적 웹페이지입니다. 자동 편성은 저장소에 공유되고 수동 편성은 최신 자료일 때만 해당 브라우저에서 우선 표시됩니다.

## 사용 방법

1. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택합니다.
2. `main` 브랜치의 `/ (root)`를 선택하고 저장합니다.
3. 저장소의 **Settings → Actions → General → Workflow permissions**에서 `Read and write permissions`를 허용합니다. 자동화 워크플로는 편성을 가져와 `schedule.json`을 갱신하고 커밋합니다.
4. **Actions → Update weekly schedule → Run workflow**로 첫 주간 편성을 가져오거나 다음 날 00:03, 00:05, 00:15, 00:30(KST) 자동 실행을 기다립니다. Pages 주소를 열면 저장소의 최신 주간 편성이 표시됩니다.

페이지 상단 `Google Sheets 수동 갱신`은 공개 시트를 브라우저에서 직접 읽어 오늘 자료를 이 브라우저의 `localStorage`에 저장합니다. GitHub 인증 토큰이나 저장소 쓰기 권한을 사용하지 않습니다. `저장된 편성 새로고침`은 GitHub 저장소의 자동 편성을 다시 읽습니다. 날짜가 아니라 요일별 시각을 비교하므로 수동 자료가 그 요일의 자동 갱신 자료보다 최신일 때만 우선 표시하고, 이후 자동 갱신이 더 새로우면 수동 자료를 자동으로 정리합니다. 수동 자료는 가져온 뒤 7일이 지나면 자동 삭제됩니다. 수동 자료는 기기 간 공유되지 않습니다. 브라우저에서 Google CSV를 읽을 수 없는 경우(예: CORS 또는 시트 공개 범위 변경) 오류를 표시합니다. 저장소를 불러올 수 없을 때는 보관된 수동 편성이 있으면 대신 표시합니다.

프로그램 카드의 별표를 눌러 즐겨찾기를 추가하거나 삭제할 수 있습니다. 편성 원본의 재방송, 생방송, 화질, 자막·화면해설·한국수어방송, 연령 등급 정보는 프로그램별 `metadata`에 저장하며, 현재 화면에는 재방송 배지만 표시합니다. 재방송이 아닌 프로그램은 제목을 더 큰 글씨로 표시해 배지 없이도 구분하기 쉽게 합니다. `metadata`는 `videoQuality`(HD/UHD 또는 null), `isLive`, `isRerun`, `hasSubtitles`, `hasAudioDescription`, `hasKoreanSignLanguage`(각각 boolean), `ageRating`(숫자 또는 null)로 구성됩니다. 기존 편성에 메타데이터가 없으면 빈 기본값으로 읽고, 해당 요일을 다음에 갱신할 때 원본 정보를 수집합니다. 처음에는 오늘 요일의 전체 편성을 표시하고, 다음 방문부터는 마지막으로 선택한 `즐겨찾기` 또는 `전체 보기` 상태를 복원합니다. 즐겨찾기는 이 브라우저의 `localStorage`에 저장됩니다. 기존 쿠키에 저장된 즐겨찾기는 페이지를 열면 자동으로 이전합니다. `즐겨찾기 백업`으로 JSON 파일을 내려받거나 `백업 불러오기`로 복원할 수 있으며, 다른 브라우저나 기기에서 사용하려면 백업 파일을 이용하세요.

요일 필터와 장르·채널 선택 메뉴에서 여러 항목을 체크해 함께 볼 수 있습니다. 각 메뉴의 `전체 선택`과 `전체 해제`로 선택을 바꿀 수 있으며, 장르·채널 필터와 `즐겨찾기`/`전체 보기` 선택은 브라우저 쿠키에 1년간 저장됩니다.

전체 요일 보기에서는 요일 카드가 기존처럼 두 열로 표시됩니다. 특정 요일을 선택하면 해당 요일의 프로그램 목록을 PC에서 두 열로 펼치며, 모바일 화면에서는 한 열로 표시합니다.

즐겨찾기가 두 줄보다 많으면 목록이 접혀 표시되고 `더 보기`로 펼칠 수 있습니다. 프로그램 이름 입력란의 제안은 가나다순으로 정렬됩니다. 오늘 편성에서는 각 채널의 다음 프로그램 시작 시각 전까지를 현재 방송 중으로 간주해 해당 카드를 은은한 색으로 강조합니다. 방송 종료 시각이 원본에 포함되지 않아 다음 편성 시각을 종료 경계로 사용합니다.

Google Sheets 편성은 GitHub Actions가 매일 00:03, 00:05, 00:15, 00:30(KST)에 읽어 저장소의 `schedule.json`에 기록합니다. 여러 시각에 실행해 예약 실행이 늦거나 누락될 때 다시 시도할 기회를 늘립니다. GitHub 스케줄러 사정으로 실제 시작이 늦어질 수 있습니다. 가져온 요일의 기존 자료만 교체하고 다른 요일은 유지하므로 주간 자료를 누적합니다. 마지막 갱신 날짜가 오늘보다 이전인 요일 카드에는 `지난 일정`과 날짜를 표시해 편성 날짜를 구분합니다. 갱신 날짜를 알 수 없는 편성에는 `날짜 정보 없음`을 표시합니다. 저장소는 공개이므로 이 편성 파일도 누구나 열람할 수 있습니다.

방송 제목 끝의 `18회`, `제18회`, `18화` 같은 회차 표기는 카드 별표로 즐겨찾기에 추가할 때 제외합니다. 따라서 다음 회차 제목도 프로그램명으로 매칭됩니다.

`편성표 CSV 가져오기`와 편성표 백업 복원은 현재 화면에서만 편성을 임시로 바꿉니다. 이 자료는 GitHub나 브라우저에 저장되지 않고 페이지를 닫으면 사라집니다. CSV는 UTF-8로 저장하고 첫 행에 아래 헤더를 넣습니다. 요일은 `월`부터 `일`로 입력합니다. CSV 장르 값은 사용하지 않으며 장르는 `genres.json` 설정에서 가져옵니다. 메타데이터 열은 모두 선택 사항이며 비어 있으면 기본값으로 처리합니다. 화질은 `HD`/`UHD`, 연령 등급은 숫자, 나머지 방송 여부는 `true`/`false`, `yes`/`no`, `1`/`0` 또는 관련 표식(예: `재방송`)으로 지정합니다. 기존 `isRerun` CSV 열도 계속 사용할 수 있습니다.

```csv
day,time,channel,title,videoQuality,isLive,isRerun,hasSubtitles,hasAudioDescription,hasKoreanSignLanguage,ageRating
월,20:50,KBS2,프로그램 이름,HD,false,false,true,false,false,12
화,21:00,MBC,다른 프로그램,UHD,true,true,false,false,true,15
```

## 프로그램 장르 분류

프로그램 제목을 키로 장르를 설정해 저장소 루트의 `genres.json`에 업로드하면 됩니다. 설정한 제목이 편성표 제목에 포함되면 적용되므로 회차나 부가 문구가 붙은 제목도 분류할 수 있습니다(대소문자 및 공백 차이는 무시). 여러 설정이 일치하면 더 긴 제목 설정을 우선 적용합니다. 설정이 없거나 제목에 맞는 설정이 없으면 `미분류`로 표시됩니다. 장르 설정은 `예능`, `교양/다큐`, `드라마` 중 하나를 사용합니다.

```json
{
  "version": 1,
  "classifications": {
    "프로그램 이름": "예능",
    "다른 프로그램": "교양/다큐",
    "주중 드라마": "드라마"
  }
}
```

`genres.json`이 GitHub Pages에 배포되면 페이지가 시작할 때 자동으로 읽습니다. 파일을 수정해 GitHub에 올린 뒤에는 Pages 배포 및 브라우저 캐시 갱신에 잠시 시간이 걸릴 수 있습니다. 장르 자동 판별과 방송사 공식 사이트 수집은 이용 조건과 데이터 품질을 확인한 뒤 별도 기능으로 검토합니다.

## 자동화에 필요한 것

- **데이터 출처**: 실제 편성 데이터는 [공개 Google Sheets 편성표](https://docs.google.com/spreadsheets/d/1D9jF3KVYAZBvYRDMzZ8oEnGwVojanrIW7FQFl4n2TOk/edit)의 CSV를 읽습니다. 이 시트를 활용하는 방법과 편성표 구성은 [「실시간확인및 출력가능한 방송편성표 만들기★」](https://blog.naver.com/starbros/221222549504)를 참고했습니다. 시트 공개 범위나 제공 형식이 바뀌면 워크플로가 실패하고 기존 `schedule.json`은 유지됩니다.
- **갱신 시각**: GitHub Actions는 UTC 기준 매일 15시 3분, 5분, 15분, 30분에 실행하며, 이는 한국 시간 00:03, 00:05, 00:15, 00:30입니다. GitHub 스케줄러 사정으로 시작 시각이 늦어질 수 있습니다. `workflow_dispatch`로 수동 실행도 가능합니다.
- **저장 위치와 공개 범위**: Actions가 갱신한 주간 편성은 공개 저장소의 `schedule.json`에 커밋됩니다. 사용자가 수동 갱신한 오늘 편성과 사용자별 즐겨찾기는 각 브라우저 `localStorage`에 남습니다. 수동 편성은 자동 편성의 요일별 갱신 시각보다 새로울 때만 적용됩니다. 사이트에는 GitHub 쓰기 토큰을 두지 않습니다.
- **장르 분류**: `genres.json`에서 제목별로 직접 지정하며, 미등록 제목은 `미분류`로 표시합니다. 공식 사이트의 자동 수집은 이용 조건과 데이터 품질을 확인한 뒤 진행합니다.

### 출처 조사 메모

2026-10-24 확인 결과, 이 프로젝트가 실제로 사용하는 편성 데이터는 위 블로그 글의 안내를 참고해 활용하는 공개 Google Sheets에서 가져옵니다. 처음 검토한 다음 검색 `IMPORTHTML` 예시는 편성 데이터의 실제 런타임 출처가 아닙니다. 실제 시트는 공개 CSV로 읽을 수 있고 지상파·종합편성·연예오락 채널을 각 탭으로 제공하며, 하루치 편성을 시간대별 채널 셀에 담습니다. Actions가 한국 시간의 현재 요일로 변환하여 `schedule.json`의 해당 요일만 교체하고 나머지 요일을 유지합니다. 셀에 여러 방송이 이어 붙은 경우 분 단위 시각과 프로그램 제목을 분리합니다. 원본에 장르는 없으므로 `genres.json`의 제목 분류를 적용하고 나머지는 `미분류`로 표시합니다.

`IMPORTHTML`은 API가 없어도 시험할 수 있는 간편한 수집 방법이지만, 원본 검색 결과의 표 구조나 인덱스가 바뀌면 수식이 깨질 수 있고 갱신 시점도 즉시라고 보장할 수 없습니다. 웹페이지가 공개되어 있다는 사실만으로 자동 수집이나 재배포가 허용되는 것은 아니므로, 사용 조건을 확인하고 개인적인 용도로만 사용해야 합니다.

- [MBC 편성 안내](https://www.imbc.com/broad/tv/guide/)
- [SBS 편성표](https://www.sbs.co.kr/schedule)
- [공공데이터포털 편성표 API 검색](https://www.data.go.kr/tcs/dss/selectDataSetList.do?dType=API&keyword=%ED%8E%B8%EC%84%B1%ED%91%9C)

공식 방송사 사이트는 공개 접근이 가능하더라도 자동 수집과 재배포가 허용된다는 뜻은 아니므로, 정책·이용 조건을 확인하기 전에는 수집하지 않습니다.
