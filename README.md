# 이번 주 편성표

방송 프로그램을 요일별로 확인하는 개인용 정적 웹페이지입니다. 별도 서버나 유료 API, 외부 패키지 없이 GitHub Pages에 올릴 수 있습니다.

> 화면에 포함된 프로그램은 사용법을 보여주기 위한 샘플이며 실제 방송 일정이 아닙니다.

## 사용 방법

1. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택합니다.
2. `main` 브랜치의 `/ (root)`를 선택하고 저장합니다.
3. Pages가 제공하는 주소를 열고 `편성표 CSV 가져오기`를 눌러 데이터를 불러옵니다.

프로그램 카드의 별표를 눌러 즐겨찾기를 추가하거나 삭제할 수 있습니다. 즐겨찾기가 있으면 방문 시 즐겨찾기 편성이 기본으로 표시되며, `전체 보기`로 전환할 수 있습니다. 즐겨찾기는 브라우저 쿠키에 저장되고 `즐겨찾기 백업`으로 JSON 파일을 내려받거나 `백업 불러오기`로 복원할 수 있습니다. 쿠키 용량 제한에 대비해 백업 파일을 별도로 보관하세요. 가져온 편성표는 브라우저 로컬 저장소에 보관됩니다.

CSV는 UTF-8로 저장하고 첫 행에 아래 헤더를 넣어주세요. 요일은 `월`부터 `일`로 입력합니다. CSV에 장르가 있어도 사용하지 않으며, 장르는 저장소의 `genres.json` 설정에서 가져옵니다.

```csv
day,time,channel,title
월,20:50,KBS2,프로그램 이름
화,21:00,MBC,다른 프로그램
```

## 프로그램 장르 분류

프로그램 제목을 키로 장르를 설정해 저장소 루트의 `genres.json`에 업로드하면 됩니다. 설정한 제목이 편성표 제목에 포함되면 적용되므로 회차나 부가 문구가 붙은 제목도 분류할 수 있습니다(대소문자 및 공백 차이는 무시). 여러 설정이 일치하면 더 긴 제목 설정을 우선 적용합니다. 설정이 없거나 제목에 맞는 설정이 없으면 `미분류`로 표시됩니다. 장르 설정은 `예능`, `교양/다큐`, `드라마` 중 하나를 사용합니다.

```json
{
  "version": 1,
  "classifications": {
    "프로그램 이름": "예능",
    "다른 프로그램": "교양/다큐",
    "주중 드라마": "드라마"
  }
}
```

`genres.json`이 GitHub Pages에 배포되면 페이지가 시작할 때 자동으로 읽습니다. 파일을 수정해 GitHub에 올린 뒤에는 Pages 배포 및 브라우저 캐시 갱신에 잠시 시간이 걸릴 수 있습니다. 가져온 편성표는 현재 브라우저의 로컬 저장소에 저장됩니다. 같은 브라우저에서는 다시 방문해도 남지만, 다른 기기와 공유되지는 않습니다.

## 자동화에 필요한 것

- **데이터 출처**: 대상 채널별 공식 API, 공개 데이터 또는 사용 허가된 피드가 있는지 확인해야 합니다. 무료로 이용 가능한 공통 편성 API가 있다고 가정하지 않습니다.
- **갱신 주기와 시간대**: 편성 정보의 갱신 주기 및 한국 시간 기준 날짜 경계를 정해야 합니다.
- **분류 규칙**: 원본에 장르가 없으므로 `genres.json`에서 프로그램 제목별로 직접 분류합니다. 미등록 제목은 `미분류`로 남습니다.
- **실행 방식**: 안정적인 공개 출처가 확인되면 GitHub Actions로 데이터를 정기 수집해 정적 JSON 파일을 갱신하고, 페이지가 그 JSON을 읽게 할 수 있습니다. 비공식 스크래핑은 사이트 이용약관과 저작권을 먼저 확인해야 합니다.

### 출처 조사 메모

2026-10-24 확인 결과, 다음 편성표 페이지에는 날짜와 채널 분류를 바꿀 수 있는 표가 있고, 공유해 주신 Google Sheets 예제도 공개 CSV로 읽을 수 있었습니다. 시트는 지상파·종합편성·연예오락 채널을 각각 나누지만 현재 하루의 시간대별 편성표입니다. 따라서 이 데이터를 주간 화면에 바로 연결하려면 날짜별 7일치 수집과 프로그램 단위 데이터 변환이 더 필요합니다. 시트 원본에 장르가 없으므로 현재는 `미분류`로 표시하고, 나중에 필요하면 제목 기반 규칙이나 수동 분류를 추가할 수 있습니다.

`IMPORTHTML`은 API가 없어도 시험할 수 있는 간편한 수집 방법이지만, 원본 검색 결과의 표 구조나 인덱스가 바뀌면 수식이 깨질 수 있고 갱신 시점도 즉시라고 보장할 수 없습니다. 웹페이지가 공개되어 있다는 사실만으로 자동 수집이나 재배포가 허용되는 것은 아니므로, 사용 조건을 확인하고 개인적인 용도로만 사용해야 합니다.

- [KBS TV 편성표](https://schedule.kbs.co.kr/)
- [MBC 편성 안내](https://www.imbc.com/broad/tv/guide/)
- [SBS 편성표](https://www.sbs.co.kr/schedule)
- [공공데이터포털 편성표 API 검색](https://www.data.go.kr/tcs/dss/selectDataSetList.do?dType=API&keyword=%ED%8E%B8%EC%84%B1%ED%91%9C)
